# Data-center-and-coal-retirement-project
This repository is for Data Center and Coal Retirement Project's open-source code.

Data source: Global power plant datasets are from Global Energy Monitor (https://globalenergymonitor.org). We derive coal plant data from Global Coal Plant Tracker (January 2025). Data center information is sourced from S&P Capital IQ Pro (https://www.spglobal.com/market-intelligence/en/solutions/products/sp-capital-iq-pro). Cement and concrete plant data for placebo test is from the Global Cement and Concrete Tracker (July 2025) (https://globalenergymonitor.org/projects/global-cement-and-concrete-tracker/). Country-level GDP per capita data is obtained from the Global Macro Database (https://www.globalmacrodata.com/).

The intermediate data will be publicable since publication.
